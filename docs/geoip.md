# GeoIP

按 IP 查国家与地点，用在两处：

- 注册页按 IP 预填国家 / 地区（需要 `country` 功能开启）。
- 活动日志里显示登录地点。

GeoIP 是一个插件（`plugins/geoip`），核心只留了一个门面 `src/GeoIP.php`。
没装插件或数据文件缺失时，两个调用点都返回空值 / 「未知位置」，页面照常工作。

## 安装

```bash
composer require geoip2/geoip2
```

发布包里没有这个依赖（`composer.json` 里是 `suggest`），因为它的数据文件有单独的许可。

然后去 MaxMind 下载 **GeoLite2-City**，放到：

```
data/GeoLite2-City.mmdb
```

文件要同意 MaxMind 的条款才能下载，不进仓库，也不随发布包分发。升级 / 搬家时记得带上。

## 启用

`config/plugins.php` 的 `enabled` 里保留 `geoip`（默认在）。插件启动时把解析器挂到核心门面上。

## 状态检查

管理员打开 `/special/geoip`，能看到：

- `geoip2/geoip2` 是否装了。
- 数据文件在不在、能不能打开。
- 用当前 IP 试查一次的结果。

三项有任何一项不正常，注册页就不预填国家，日志地点显示「未知位置」。

## 降级行为

| 情况 | 表现 |
|---|---|
| 插件没启用 | 不预填、地点显示「未知位置」 |
| 依赖没装 | 同上 |
| 数据文件缺失 / 损坏 | 同上，错误日志里有 `[GeoIP]` 记录 |
| 内网 / 本地 IP | 地点显示「本地」或「未知位置」 |

这些都不影响注册和登录，只是少一个便利功能。
