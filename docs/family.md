# 家庭与监护

面向未成年用户的账号监护。**默认关闭**，开启方式见下。

## 开关

`config/installed.php`：

```php
'app' => [
    'features' => [
        'guardians' => true,
    ],
],
```

或环境变量 `FEATURE_GUARDIANS=1`。安装向导的「扩展」一步也能勾。关掉后注册不要求家长邮箱，
`/family` 及家庭相关分支全部不出现。

## 年龄判定

注册时填的出生日期 + 国家/地区，对照 `config/consent-age.php` 里的各国同意年龄：

- 低于该国年龄 → 未成年，注册时要求填家长邮箱。
- 国家/地区功能关闭、或没填国家 → 用 `consent-age.php` 的 `default`（16 岁）。
- 各国年龄和来源在 `config/consent-age.php` / `consent-age-sources.php`，改之前先确认当地法律。

同意年龄是产品策略，不是法律意见。

## 家长和孩子的关系怎么建立

两种方向：

**孩子注册时填家长邮箱**。系统给家长发邀请。家长用自己的邮箱注册（或已有账号），
在家庭页点「加入」即可；如果家长的账号邮箱就是被邀请的地址，一键加入，不用再验证一次。

**家长新建孩子账号**。家长在家庭页直接建一个孩子账号，填账号名、密码、出生日期等。
每天最多建 5 个。

一个家庭可以有多位家长。家长可以在家庭页里再邀请一位家长（填关系：父亲 / 母亲 / 其他）。

## 家长能做什么

只有两样：

- **重置孩子密码**：给孩子账号的联系邮箱发验证码，凭码设置新密码。重置后会退出孩子账号的其他设备。
- **临时锁定 / 解锁账号**：锁定后孩子立刻被退出登录，且无法登录。

**家长看不到孩子的密码、消息，也不能以孩子身份登录。** 权限就上面两条，不要按「完全托管」理解。

## 停止监护

这是**孩子自己的动作**，家长没有反向解除的入口。家庭页会逐条列出不满足的条件：

| 条件 | 说明 |
|---|---|
| 家长已经加入 | 只是邀请、还没接受时没有监护可停 |
| 绑定自己的邮箱 | 联系地址还是家长邮箱时不行 |
| 到了所在地区的独立使用年龄 | 按 `consent-age.php` 判断 |
| 账号创建满 6 个月 | 防止刚注册就脱离监护 |

全部满足后孩子可以在家庭页点「停止监护」。停止后关系变为 `independent`，家长不再有重置密码和
锁定的权限。

## 未成年账号与账号恢复

处于监护关系中的未成年账号**不能走账号恢复申诉**，页面会提示联系家长。理由同上：
找回责任在监护人，家长可以直接重置密码。

## 数据与状态

| 表 | 内容 |
|---|---|
| `family_groups` | 家庭组，含家长邮箱、同意时间 |
| `family_members` | 成员关系：家长 / 孩子、状态、关系称谓 |

成员状态：`pending`（邀请中）、`active`（已加入）、`independent`（监护已结束）、`removed`（已离开）。

## 相关配置

| 键 | 位置 | 说明 |
|---|---|---|
| `features.guardians` | `config/installed.php` / `FEATURE_GUARDIANS` | 总开关 |
| `default` / `ages` | `config/consent-age.php` | 同意年龄 |
| `guardians` 相关限流 | 控制器内常量 | 建孩子账号每天 5 个；邀请、认领、重置各有每日上限 |
