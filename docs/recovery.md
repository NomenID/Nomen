# 账号恢复

「账号恢复」管的是**密码和第二因素都进不去**的情况，不是普通的忘记密码。改密码在设置页里做；
登录前的邮箱验证码登录也能救回大部分「只忘了密码」的用户。

## 流程

```
用户过了第一因素 → 二验页点「无法验证」
        ↓
填写申诉（身份信息 + 说明 + 证明材料）
        ↓
管理员在后台审核
        ↓
批准：给联系邮箱发一次性恢复链接（7 天）
        ↓
链接打开 → 强制安全修复 → 完成，恢复访问
        ↓
拒绝：发通知邮件，工单留拒绝原因（不发给用户）
```

申诉入口需要「刚刚登录过、但卡在第二因素」的会话上下文。直接打开 `/recovery` 没有上下文，
会被送回登录页并提示重新登录后再申请。上下文有效期 `recovery_ctx_ttl`（默认 2 小时）。

## 申诉表单

| 字段 | 说明 |
|---|---|
| 出生日期 | 用于核对身份，也用于判断是否未成年 |
| 性别 | 核对用 |
| 说明 | 账号情况、能证明身份的信息 |
| 联系方式 | 管理员联系你用 |
| 临时邮箱 | 接收审核结果和恢复链接的地址 |
| 证明材料 | 图片，单张最大 1MB，最多 5 张 |

限制（都在 `config/app.php`）：

| 项 | 默认 |
|---|---|
| 单 IP 提交上限 | 5 次 / 小时 |
| 单 IP 上传上限 | 40 次 / 小时 |
| 未提交附件的保留时间 | 2 小时 |

附件存在 `public/assets/recovery/`，不进仓库，迁移和换服务器时记得一起带走。

## 未成年账号

开启了家庭与监护、且账号处于「家长已加入」的监护关系时，**不能用账号恢复**，页面会提示联系家长。
家长在家庭页可以直接重置孩子密码。这是有意的：未成年账号的找回责任在监护人，不在站长。

## 管理员审核

后台「恢复工单」页：

- 列表按状态筛选，详情里能看到用户填的全部信息、附件和账号当前状态。
- **批准**：生成一次性恢复链接，发到用户填的联系邮箱，同时给账号邮箱发一封提醒（已验证时）。
  链接有效期 `recovery_token_ttl`（默认 7 天），只能使用一次；重新批准或「重发」会立刻作废旧链接。
- **拒绝**：必须填写原因，原因只记录在工单里，邮件只告诉用户「未通过」。
- 工单状态：`pending` / `approved` / `rejected` / `completed`。

新工单的提醒发给 `admin_notify_email`。提醒按 `admin_notify_window` 节流（默认 86400 秒），
窗口内只发一封汇总，不会每单都发。

## 一次性恢复链接

用户点开链接后：

1. 服务端校验令牌，**立刻标记已使用**，并清掉该账号的其他会话、OAuth 令牌和第三方应用授权。
2. 会话进入恢复模式。在此期间除了修复所需的页面，访问其他页面都会被拉回 `/recovery/secure`。
3. 必须完成两件事才能结束：
   - **重置凭据**：改密码，或者添加一个新邮箱并点完验证链接（只是提交不算）。
   - **至少 3 种登录方式**：密码 / 邮箱 / 恢复码 / 验证器 APP 里数满 3 种。生物识别和临时密钥
     不计入——一个绑在设备上，一个是临时凭据。
4. 点「完成」后：撤销其他设备会话、撤销全部 OAuth 令牌、删除全部第三方应用授权，发完成邮件，
   退出恢复模式。

恢复模式里创建 TOTP、生成恢复码会跳过密码校验——旧密码正是问题所在。

## 相关配置

| 键 | 位置 | 说明 |
|---|---|---|
| `recovery_ctx_ttl` | `config/app.php` | 申诉上下文有效期 |
| `recovery_submit_limit` / `recovery_submit_window` | 同上 | 提交限流 |
| `recovery_token_ttl` | 同上 | 恢复链接有效期 |
| `recovery_attach_max_bytes` / `recovery_attach_max_count` | 同上 | 附件限制 |
| `recovery_attach_tmp_ttl` | 同上 | 未提交附件保留时间 |
| `recovery_upload_limit` / `recovery_upload_window` | 同上 | 上传限流 |
| `admin_notify_window` | 同上 | 新工单提醒节流 |
| `support_email` | 品牌配置 | 恢复页给用户的联系地址 |
| `admin_notify_email` | 品牌配置 | 新工单提醒收件人 |
