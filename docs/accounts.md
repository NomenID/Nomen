# 账号与登录

## 注册

注册页是分步表单，按顺序是：账号名 → 密码 → 国家/地区（可选功能开启时）→ 个人信息
（出生日期、性别）→ 邮箱。

- 账号名和邮箱唯一；邮箱不区分大小写。
- 必须勾选同意隐私政策和服务协议，两个都勾才能提交。
- 密码规则由前端提示，后端同样校验；pepper 参与哈希后入库。
- 邮箱已经属于一个**未验证**的账号时，不会直接报错，而是进入 `/register/verify`：
  给那个邮箱发验证码，证明邮箱是你的之后回收该账号继续注册。
- 个人信息的出生日期用于判断是否需要家长同意（见 [家庭与监护](family.md)）；国家/地区只有在
  `country` 功能开启时才出现，默认按 IP 预填，用户可以改。

注册完成后账号处于「未验证邮箱」状态，除激活流程外，访问其他页面都会被拉到 `/activate`。
激活方式：邮件里的链接，或在激活页重新发信后输入验证码。

## 登录方式

五种方式，后台「登录方式」页可以逐个开关：

| 方式 | 入口 | 说明 |
|---|---|---|
| 密码 | `/login` 密码页签 | 用户名 / 邮箱 + 密码 |
| 邮箱验证码 | `/login` 验证码页签 | 给已验证邮箱发 6 位码；需要配好 SMTP |
| 临时密钥 | `/fast-pass` | 用户名 + 事先在设置页生成的临时密钥；应急通道 |
| 生物识别 | `/login` | WebAuthn（指纹 / 人脸 / 安全密钥），需要先在设置页登记 |
| 第三方登录 | `/login` | 已启用的 OAuth 提供方，见 [第三方登录](oauth-providers.md) |

规则：

- **至少要留一种可用方式**，后台关闭最后一个会被拒绝。第三方登录要算「可用」，得有至少一个已启用的提供方。
- 关掉密码登录后，注册页只剩第三方登录按钮；`/register` 的密码表单隐藏。
- 五种方式都关了、后台进不去时，跑 `php bin/nomen auth:reset` 恢复成全部开启。

### 临时密钥

设置页 →「临时密钥」生成。规则：

- 至少 10 位，必须同时包含大写字母、小写字母和数字。
- 同时最多 5 个有效密钥，单个最长 14 天。
- 登录时同时要用户名和密钥；**临时密钥不参与两步验证**，是应急通道。
- 服务端只存 Argon2id 哈希，生成后密钥本身只显示一次。

## 会话与设备

| 项 | 默认 | 位置 |
|---|---|---|
| 未登录访客的会话 | 2 小时 | `config/app.php` 的 `session_lifetime` |
| 登录保持 | 30 天没访问就重新登录，每次访问自动续期 | `login_ttl` |
| 最长登录期 | 从登录时刻起 90 天 | `login_max_ttl` |
| 公共设备 | 勾选后只发浏览器会话 cookie，关浏览器即退出 | 登录页 |
| 可信设备判定 | 90 天内验证过 | `src/DeviceController.php` |
| 会话 cookie 名 | `NOMEN_SESSION` | `BRAND` 的 `session_name` / `SESSION_NAME` |

设置页的「设备」区能看当前登录过的设备，可以单个撤销或全部退出。撤销其他设备会同时清掉那些
设备上的会话；改密码、完成账号恢复也会做这件事。

## 设置页

| 区块 | 能做的事 |
|---|---|
| 资料 | 昵称、头像、简介、性别等 |
| 密码 | 改密码；忘记旧密码时可以先给邮箱发验证码，凭码重置 |
| 邮箱 | 最多 5 个地址，可设首选、重发验证、删除；验证链接 24 小时有效 |
| 设备 | 查看、撤销登录设备 |
| 两步验证 | 用户级策略、TOTP、恢复码，见 [两步验证](two-factor.md) |
| 临时密钥 | 生成、查看列表、删除 |
| 生物识别 | 登记、删除 WebAuthn 凭据 |
| 通知 | 三类站内通知的邮件投递开关 |
| 语言 / 皮肤 | 选择界面语言、切换已启用的皮肤 |

删除邮箱、换首选邮箱这类操作要求该地址已验证。最后一个已验证邮箱不能删——它是找回账号的凭据。
