# nomen-ssr（轻量皮肤）

没有星图、没有卡片堆叠，文字优先、窄栏阅读。首页和文档都由 PHP 直接输出。

## 目录

```
nomen-ssr/
├── skin.json
├── layouts/
│   ├── default.php        普通页面：极简页头、窄栏正文、朴素页脚
│   ├── app.php            应用区（仍然要 Vue 外壳）
│   └── admin-app.php      后台
├── partials/footer.php
├── templates/home.php     覆盖核心首页，改成文字优先的版式
└── i18n/
```

## 特点

- **`templates/home.php`** 覆盖了核心默认首页：标题、一段说明、几个链接，没有能力卡和按钮组。
- **无星野背景**：不 `require` `_site_sky`，页面底色就是 `--color-bg`。
- **窄栏**：`max-width` 收窄，行高放宽，适合长文。
- **仍然用核心 CSS**：不另写一套样式表，换它只是换布局和首页版式。

## 什么时候选它

- 站点主要在写文档（配合 Pages 插件），访客是来读东西的。
- 服务器弱、想少加载一点东西（它的布局里没有多余装饰）。
- 不喜欢深色星空的观感。

## 和默认皮肤的差别

| | nomen-2026 | nomen-ssr |
|---|---|---|
| 星野背景 | 有 | 无 |
| 首页 | 核心默认首页（标题 + 按钮 + 区块） | 覆盖成文字优先版式 |
| 认证页 | 居中卡片 | 同核心样式，窄栏 |
| 页脚 | 版权 + 链接 + Powered by | 同样三样，更朴素 |
| 前端产物 | 都要 | **都要**（应用区和后台是 Vue，这部分省不掉） |

**它并不是「无 JS」皮肤**：`/dashboard`、`/settings`、`/admin` 仍然是 Vue 单页。它省掉的是首屏装饰，
不是前端框架。

## 坑

- **覆盖了 `home.php`**：站长在后台把首页切成「Pages 页面」或「自定义模板」时，这个覆盖就不生效了。
- **窄栏 + 宽表格**：文档里的大表格会横向溢出，Pages 的样式已经在处理，自己写模板时注意 `overflow-x: auto`。
- **别删 `app.php`**：有人以为「SSR 皮肤不需要 Vue」把它删了，结果 `/dashboard` 直接 500。
