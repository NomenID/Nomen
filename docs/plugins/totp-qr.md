# TOTP QR：本地画二维码

两步验证设置页那个二维码，由这个插件在**浏览器里**画出来。不装的话设置页只显示密钥文本，让用户手动输入。

为什么单独做成插件：以前是把 `otpauth://` 地址拼进第三方二维码服务的 URL，等于把二验密钥送给对方。
现在密钥不出站。

## 装上

随包自带、默认启用，**不需要任何配置**，也不需要建表。

## 它怎么起作用

插件提供一个全局对象：

```js
window.NomenQr = {
    render: function (uri) { return { size: 200, path: 'M...' }; }
};
```

核心的设置页（Vue 组件 `TotpSection`）拿到 `{size, path}` 就画 `<svg>`；拿不到就降级成「无法加载二维码，
请手动输入密钥」。所以：

- 插件被停用 → 功能降级，不报错。
- 插件加载失败 → 同上。
- 想换实现（比如改用 WebAssembly 的 QR 库）→ 保持这个接口就行。

只在 `/settings` 和 `/recovery/secure` 这两个页面登记加载，别处不加载。

## 实现说明

编码器是自带的（`assets/qr.js`）：字节模式、纠错等级 M、版本 1–10、自动选掩码。没有外部依赖，
不请求网络，也不读 `window` 之外的任何东西。

## 坑

- **别在别的页面手动加载 `qr.js`**：它注册全局对象，重复加载没意义。
- **别把密钥写进 `console.log`**：调试二维码时最容易犯这个，浏览器控制台会被截图、会被插件读。
- **深色主题**：二维码要在白底上扫，核心已经处理了背景色；自己改样式时别把底色改成深色。
- **密钥长度决定版本**：超长密钥（>32 字节）会用到更高版本，`qr.js` 支持到版本 10；再长就画不出来。

## 检查清单

- [ ] `/settings` 里能出二维码
- [ ] 用手机扫码能加到验证器
- [ ] 停用插件后页面不报错（降级成手动输入）
- [ ] 页面上没有把密钥打到控制台
