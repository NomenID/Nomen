# 管理后台

后台地址 `/admin`，要管理员账号。未登录访客访问 `/admin` 得到 403，这是正常行为，不是错误页。

后台是 Vue SPA，界面固定中文。数据走 `/api/admin/*`，动作仍走原来的 POST 路径。

## 页面

| 页面 | 路径 | 作用 |
|---|---|---|
| 概览 | `/admin` | 站点统计、插件 / 版本、缓存与邮件状态、最新正式版检查 |
| 首页 | `/admin/homepage` | 首页模式、标题、副标题、按钮、底部链接 |
| 用户 | `/admin/users` | 用户列表、详情、启用 / 禁用、授予 / 撤销管理员 |
| 应用 | `/admin/apps` | OAuth 客户端管理：新建、改配置、重置密钥、启停、删除 |
| 登录方式 | `/admin/identities` | 五种登录方式总开关、第三方提供方管理 |
| 接入点 | `/admin/mounts` | 协议端点与插件挂载点，能改路径的可以直接改 |
| 恢复工单 | `/admin/recovery` | 账号恢复申诉的审核 |
| 活动日志 | `/admin/logs` | 操作日志，可筛选、看详情、导出 |
| 设置 | `/admin/settings` | 两步验证策略、缓存后端、站点 API 开关 |
| 内容 | `/admin/content` | Pages 插件页；全部 / 已发布 / 草稿 / **目录**（每个目录的侧边栏） |
| 开发者 | `/admin/developers` | 开放平台插件页；开发者与名下应用 |

插件用 `Admin::page()` 注册的页面也出现在这里，分组和顺序由插件清单决定。

## 概览

- 用户数、应用数、恢复工单等统计。
- 「当前版本」和「最新正式版」：最新版通过官方站 `https://nomenid.org/api/version` 查询，
  结果缓存 30 分钟。拉不到只显示当前版本，不报错。
- Redis、缓存后端、邮件配置状态。

有新版时「当前版本」旁会出现黄标，链接到官方站的下载页。

## 首页

三种模式：默认首页、指定页面、自定义模板。默认模式的标题、副标题、两个按钮都能改。
底部链接可以单独隐藏默认三条（文档 / 开放平台 / 版本信息），也可以加自定义链接。

插件通过 `homepage.links` 钩子加的链接会标「由 X 托管」，后台不能直接改，只能由插件处理。

## 用户

列表支持按用户名 / 邮箱搜索。详情页能看：

- 基本资料、邮箱与验证状态、注册时间、最近登录。
- 登录方式、两步验证状态、可信设备。
- 已授权的第三方应用，可逐个撤销。
- 恢复工单历史。

启用 / 禁用账号、授予 / 撤销管理员都会记活动日志。

## 应用

核心的 OAuth 客户端管理，不依赖开放平台插件。字段和规则见 [开放平台](open-platform.md)。

**client_secret 只在创建时显示一次**，之后只存哈希。丢了只能重置。

## 登录方式

上半部分是五个总开关：密码、邮箱验证码、生物识别、临时密钥、第三方登录。关到没有可用方式时保存会失败。

下半部分是第三方提供方列表，可以新增、编辑、启停、删除。配置细节见 [第三方登录](oauth-providers.md)。

## 接入点

列出：

- 协议端点：`/oauth/authorize`、`/oauth/token`、`/api/userinfo`、`/api/token-info`、`/oauth/revoke`。
- 插件挂载点：Pages 的 `/w`、开放平台的 `/open`。

带 `config` 的挂载点可以直接改路径，写入 `config/plugins/<slug>.json`。

## 恢复工单

列表按状态筛选，详情里看申诉信息和附件。批准 / 拒绝 / 重发见 [账号恢复](recovery.md)。

## 活动日志

记录登录、改密、改邮箱、2FA 变更、管理员操作、恢复流程等。可以按分类和关键词筛选，支持导出。

## 设置

| 项 | 值 |
|---|---|
| 登录两步验证 | `off` / `new_device` / `every_login` |
| 缓存后端 | `auto` / `redis` / `file` / `db` + 插件注册的驱动 |
| 站点 API | 开 / 关 |

保存后下一次请求生效，并写活动日志。
